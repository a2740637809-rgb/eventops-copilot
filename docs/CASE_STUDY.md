# EventOps Copilot｜一页 Case Study

我将 160+ 场婚礼、商业活动和校园活动经验抽象为一个 AI 活动运营工作台。项目解决的不是“快速写方案”，而是资料分散导致的遗漏、冲突和执行版本不可信。

核心决策是证据优先：系统先建立事实登记册，缺项保持空白，冲突阻塞审批；执行包中的每项内容区分资料事实、人工确认和模板建议。确定性规则处理时间冲突与审批门槛，RAG 负责检索和引用，MVP 不使用多 Agent。

当前版本提供可交互工作台、合成案例、合成评测、运行轨迹和模拟日历调用。由于无法获得真实从业者和真实资料，本项目不展示虚构反馈或效率提升；真实用户修改率与任务完成率明确列为下一验证。
