# EventOps Copilot PRD

## 一句话定位

面向中小型线下活动执行人员，把分散资料转化为有来源、可审批、可执行的活动执行包。

## MVP 闭环

资料导入 → 事实核对 → 缺项/冲突 → 执行包 → 人工审批 → 模拟或真实工具调用 → 轨迹与评测。

## 本版本状态

- 已实现：合成资料、事实来源、冲突和缺项、执行包、审批门槛、模拟日历、轨迹、合成评测。
- 模拟：文件解析结果、模型运行、日历调用、成本。
- 待配置：真实模型 API、真实 OAuth 日历写入。
- 待验证：真实资料解析质量、真实用户修改率与任务完成率。

## 非目标

报名售票、签到、营销自动化、供应商采购、多租户、多人实时协作和多 Agent。
