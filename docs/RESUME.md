# 简历项目描述

**EventOps Copilot｜AI 活动运营 Agent（产品设计与独立开发）**

- 基于 160+ 场活动主持与执行经验，设计“资料核对—冲突识别—执行包—人工审批—工具调用—复盘评测”的 AI 产品闭环。
- 建立带文件定位和原文引用的活动事实模型，通过确定性规则识别时间/人员冲突，并对缺失信息强制提问，避免无依据生成。
- 采用 Next.js、TypeScript、RAG 扩展接口和审批门槛实现可运行 MVP；以合成评测集追踪遗漏率、准确率、冲突召回率、工具成功率、耗时和成本。
- 对真实能力、模拟调用和待验证项进行显式标注，不虚构用户反馈或效率数据。
