# 50 秒演示视频脚本

| 时间 | 画面 | 旁白 |
|---|---|---|
| 0–6s | 首页与产品定位 | 活动执行最怕的不是方案不漂亮，而是一个关键要求被漏掉。 |
| 6–14s | 进入工作台、准备度 | EventOps Copilot 先把分散资料变成事实登记册，而不是直接生成。 |
| 14–23s | 展开日期来源 | 每项事实都能回到文件位置和原文；没有依据的字段保持缺失。 |
| 23–31s | 问题中心 | 系统主动暴露时间冲突和缺项，阻塞问题没有解决就不能放行。 |
| 31–40s | 执行包 | 确认后生成时间轴、岗位、物料和风险，并区分资料事实与模板建议。 |
| 40–47s | 审批与模拟工具 | 外部操作必须人工审批；公开 Demo 只模拟日历调用，不伪装真实集成。 |
| 47–53s | 评测页 | 所有结果来自合成评测，真实用户效果明确列为待验证。 |
